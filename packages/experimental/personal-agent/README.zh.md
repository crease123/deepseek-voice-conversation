# 通话上下文服务

此模块保留旧包名与 `personalAgent` 接口以兼容现有客户端，但不再注册任何 Agent preset，也不注入基础人设。

在任意会话中开启通话时，客户端先通过 `call` 流登记 Session；后续模型请求通过 System Prompt 上下文注入 `callPrompt`。挂断、断连、Session 关闭或服务卸载均撤回通话状态，多客户端独立计数。开启或结束通话不创建用户消息、不触发额外模型请求。

「设置 → 通话提示词」只编辑通话规则。旧 `basePreset`、`basePrompt` 仅为配置兼容保留，不再生效；当前会话的原人设、工具和权限不变。
